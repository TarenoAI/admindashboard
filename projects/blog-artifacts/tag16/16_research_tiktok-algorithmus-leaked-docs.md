# TAG-16 Research — TikTok Algorithm “Leaked Docs”

## Research Objective
Build an authority-grade article that explains what leaked algorithm material can and cannot be used for in real TikTok growth operations.

## Core Questions
1. Which leak-derived ideas are stable enough to test?
2. Which parts are too volatile to treat as rules?
3. How can teams operationalize algorithm learning without superstition?

## Evidence Priorities
- Platform-owned documentation and creator resources
- Product documentation from tools used in workflow implementation
- Reproducible practitioner experiments with transparent methodology

## Stable Insights to Carry into Outline
- Viewer behavior signals are central to recommendation expansion.
- Early relevance and retention influence downstream distribution.
- Content clarity and consistent topic positioning improve audience matching.
- Batch-level testing outperforms one-off interpretation.

## Volatile/High-Risk Claims to Avoid as Absolutes
- Exact ranking weights
- Hard universal posting-time formulas
- Single-metric growth guarantees

## Content Gaps Found in Typical Competitor Articles
- Heavy on myths, weak on measurement design
- Lists tactics without decision thresholds
- No clear distinction between hypothesis and validated pattern

## Required Topic Anchors
watch time distribution, completion tendency, rewatch trigger, saves vs shares, opening architecture, distribution waves, batch testing, decision thresholds

## Drafting Requirements for Authority Mode
- Factual first 300 words
- Named framework with practical components
- Include trade-offs and edge cases per core section
- Include a concrete testing protocol
- Include FAQ with non-duplicative, specific answers
