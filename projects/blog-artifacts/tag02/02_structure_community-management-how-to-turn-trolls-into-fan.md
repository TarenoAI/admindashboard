# Community Management: How to Turn Trolls into Fans

## Quick Definition
A practical system for community management tips that helps teams improve consistency and outcomes. It focuses on clear workflows, measurable actions, and low-friction execution.

## Named Framework
### CLEAR Loop
- **C**larify objective
- **L**imit complexity
- **E**xecute consistently
- **A**ssess outcomes
- **R**efine weekly

## When to Use / When Not to Use
### Use when
- You need repeatable execution
- Team handoffs create friction
- You want cleaner performance feedback

### Avoid as primary fix when
- Strategy is undefined
- You cannot maintain weekly cadence

## Comparison Checklist
- Structured workflow vs ad-hoc actions
- Clear ownership vs unclear handoffs
- Weekly optimization vs random updates

## Step-by-Step
1) Define one weekly objective
2) Set one primary KPI
3) Implement workflow
4) Review and adjust
