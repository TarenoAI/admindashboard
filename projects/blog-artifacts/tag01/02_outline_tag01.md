## H1
Social Media Automation für Anfänger: Der 6-Schritte-Workflow für 10h Zeitersparnis pro Woche

## GEO-Pflichtblöcke

### 1. TL;DR (3-5 Bullets)
- Batch-Produktion statt täglichem Ad-hoc Posting spart bis zu 10h/Woche
- Fokus auf 1-2 Kernkanäle statt Flächenbeschuss
- Content-Kalender mit Puffer = Stressfreiheit
- Automation = Workout, nicht Ersatz für Strategie
- Framework FAKTOR-6 strukturiert Einsteiger

### 2. Quick Definition (2 Sätze)
Social Media Automation ist die systematische Planung, Erstellung und Veröffentlichung von Content in zeitlich gebündelten Blöcken. Ziel ist konstante Sichtbarkeit bei minimiertem operativem Aufwand.

### 3. Named Framework: FAKTOR-6
**F**okus definieren (Zielgruppe + Kernkanäle)
**A**ssets erstellen (Content-Puffer aufbauen)
**K**anäle wählen (1-2 Plattformen für Start)
**T**iming festlegen (Beste Posting-Zeiten)
**O**utput planen (Redaktionsrhythmus)
**R**eview & Optimieren (KPIs tracken)

### 4. When to Use / When Not to Use
**Nutzen wenn:**
- Zeitmangel durch manuelles Posten
- Unregelmäßige Präsenz
- Mehrere Kanäle bespielt werden

**Nicht nutzen wenn:**
- Keine klare Zielgruppe definiert
- Keine Content-Strategie vorhanden
- Reiner Spam/automatisierte DMs gewünscht

### 5. Comparison Element (Checklist)
| Ohne Automation | Mit Automation |
|-----------------|----------------|
| Tägliches Ad-hoc Posten | Wöchentliche Batch-Erstellung |
| Stress bei Content-Lücken | Puffer von 1-2 Wochen |
| Unregelmäßige Zeiten | Optimale Posting-Slots |
| Hoher Zeitaufwand | Systematisierte Workflows |
| Keine Planung | Data-driven Content-Strategie |

### 6. FAQ (min. 5)
- Was ist der größte Vorteil?

- Wie lange dauert die Einrichtung?
- Kann ich auch Stories/Reels automatisieren?
- Was kostet Social Media Automation?
- Ist Automation für alle Plattformen gleich?
